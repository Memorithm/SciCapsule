# SciCapsule

SciCapsule is the product repository for SciRust portable, reproducible execution capsules.

The reusable `.scicap` format and verification primitives belong in the `Memorithm/scirust` monorepo so they can be shared by the rest of the SciRust ecosystem. This repository contains the independently distributable SciCapsule product layer built on those primitives.

Development is intentionally PR-driven after this bootstrap commit.
